# جمعيتي — النسخة النهائية المعدلة

تطبيق PWA محلي لإدارة العملاء والأصناف والمخزون والصرف والفواتير.

## أهم الوظائف
- عملاء: إضافة/تعديل/أرشفة/بحث، مع رقم البطاقة والرقم السري والبيانات الاختيارية.
- أصناف: كود تلقائي، سعر، وحدة، حد أدنى، مخزون، وإضافة مخزون كحركة مستقلة.
- صرف: فحص المخزون، منع تكرار صرف نفس العميل في نفس الشهر، تأكيد نهائي.
- الفاتورة الأصلية لا تُحذف؛ يوجد عكس عملية يعيد المخزون ويحفظ الأصل.
- حالات العملاء الشهرية: تم الصرف / لم يصرف / متأخر.
- بحث الفواتير بالرقم أو الاسم أو رقم البطاقة.
- Backup / Restore.
- PWA + Service Worker للعمل Offline بعد تحميل النسخة من HTTPS.

## مهم
البيانات محلية على الجهاز وليست مزامنة بين الأجهزة. GitHub Pages عام، فلا تضع بيانات عملاء حقيقية في نسخة عامة بدون حماية مناسبة.
