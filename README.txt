جمعيتي — النسخة النهائية مع المخزون

هذه الحزمة تحافظ على بيانات IndexedDB باسم GamayatiDB ولا تتعمد إنشاء قاعدة جديدة.

المضاف/المصحح:
- مخزون لكل صنف.
- استلام مخزون مع الكمية والتاريخ والوقت والملاحظة.
- سجل حركات المخزون: استلام، صرف، عكس صرف، تعديل/رصيد افتتاحي.
- فتح تفاصيل الفاتورة.
- سجل شهور العميل.
- الرقم السري للعميل يُدخل يدويًا ولا يتم توليده تلقائيًا.
- Service Worker خاص بجمعيتي وكاش مستقل.

لا تحذف بيانات الموقع ولا تستخدم زر حذف البيانات أثناء التحديث.
