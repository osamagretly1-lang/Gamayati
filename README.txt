تحتوي على العملاء، الرقم السري اليدوي، الأصناف، المخزون وسجل حركاته، الصرف والفواتير، سجل الشهور، النسخ الاحتياطي والاسترجاع، وتقرير Excel لشهر أو 3 شهور.

المهم: استبدل ملفات النسخة الحية بهذه الملفات فقط داخل مستودع GitHub Pages، ولا تخلط معها نسخ app/index أخرى بأسماء مختلفة.
