جمعيتي v0.2 — نسخة تشغيل فعلية أولية

هذه ليست مجرد واجهة: IndexedDB تحفظ البيانات محليًا، والصرف ينفذ معاملة واحدة تشمل الفاتورة + بنودها + خصم المخزون + سجل حركة المخزون + سجل التدقيق. إذا فشلت المعاملة يتم إلغاؤها.

موجود:
- عملاء: إضافة/تعديل/أرشفة/بحث.
- أصناف: سعر/وحدة/مخزون/حد أدنى.
- صرف نهائي مع فحص المخزون.
- منع الصرف المكرر لنفس العميل في نفس الشهر.
- فاتورة غير قابلة للحذف من الواجهة.
- عكس الفاتورة بدل حذفها مع إرجاع المخزون وحفظ الأصل.
- حالة شهرية أخضر/أصفر/أحمر، ويوم نهاية الدورة قابل للتعديل.
- Backup وRestore.
- PWA service worker للتشغيل Offline بعد أول تحميل من HTTPS.

مهم:
- لا تضع بيانات عملاء حقيقية في نسخة منشورة للعامة قبل إضافة طبقة حماية/تسجيل دخول مناسبة. GitHub Pages عام.
- لا يوجد مزامنة بين هاتفين؛ البيانات محلية على الجهاز.
- هذه MVP حقيقية وليست النسخة الإنتاجية النهائية. يلزم اختبار ميداني، خصوصًا حالات التزامن، واستكمال التقارير والمدفوعات وصلاحيات المستخدمين قبل الاعتماد الرسمي.
