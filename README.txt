جمعيتي v05

نسخة عملية PWA محلية Offline-first لإدارة العملاء والأصناف والمخزون والصرف والفواتير.

المهم:
- البيانات محلية على نفس الجهاز عبر IndexedDB.
- البحث السريع عن العميل في «صرف جديد» بالاسم أو رقم البطاقة.
- كل فاتورة مستقلة وتفتح بتفاصيلها.
- الفاتورة لا تُحذف؛ التصحيح يكون بعكس العملية مع إرجاع المخزون والإبقاء على الأصل.
- سجل العميل يعرض كل الشهور من بداية تسجيله حتى الشهر الحالي، مع حالة الصرف لكل شهر.
- ملاحظات مستقلة للعميل ولمستوى الفاتورة.
- المخزون محفوظ منفصلًا لكل صنف ولا توجد عملية جمع لكميات أصناف مختلفة.
- استلام مخزون متكرر لكل صنف.
- سعر الصنف يؤثر على العمليات الجديدة فقط، والفاتورة القديمة تحفظ سعرها وقت الصرف.
- أرشيف للعملاء والأصناف بدون حذف البيانات.
- Backup / Restore.
- حماية حذف كل البيانات بتأكيدات متعددة وكلمة مرور.
- PWA مع أيقونات PNG 192/512 وService Worker بإصدار v05.

تنبيه: GitHub Pages عام. لا تضع بيانات عملاء حقيقية على نسخة عامة دون طبقة حماية مناسبة. النسخ الاحتياطي مشفر؟ لا، ملف النسخة الاحتياطية JSON عادي ويجب حفظه بأمان.
