جمعيتي — النسخة النهائية المدمجة

هذه النسخة مبنية على النسخة المستقرة، مع الاحتفاظ بكل الوظائف الأساسية، وإضافة/إصلاح: 
1) سجل كل الشهور للعميل من أول شهر توجد له فيه فاتورة محفوظة حتى الشهر الحالي، مع فتح الفاتورة عند وجود عملية.
2) تقرير Excel أكثر توافقًا: يقرأ قاعدة البيانات مباشرة وقت التصدير ويضع البيانات في أوراق قابلة للفتح، مع ورقة لكل البيانات الموجودة على الجهاز.
3) تحديث Service Worker ونسخة الكاش لضمان تحميل ملفات النسخة الجديدة.

قاعدة البيانات: GamayatiDB — DB_VERSION 6.
